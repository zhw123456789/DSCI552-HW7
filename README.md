# DSCI 552 Homework 7

Install the dependencies with `python -m pip install -r requirements.txt`.
Open `notebook/Zhang_Hanwen_HW7.ipynb` in Jupyter and run all cells from the notebook directory.

The notebook loads `data/Frogs_MFCCs.csv` using a relative path. The SVM cross-validation and 50 K-means trials can take several minutes.

Data source: Colonna et al., [Anuran Calls (MFCCs)](https://doi.org/10.24432/C5CC9H), UCI Machine Learning Repository, CC BY 4.0.
